# SwiftBasket — Quick-Commerce Analytics

An end-to-end **quick-commerce analytics project** inspired by platforms like Zepto, covering synthetic data generation, PostgreSQL, SQL business analysis, and Power BI reporting.

The project analyzes **customers, orders, products, inventory, dark stores, riders, deliveries, payments, and returns** to derive actionable business insights.

---

## Project Overview

- **300,000 orders**
- **873,055 order-detail records**
- **8 interconnected datasets**
- **50 business SQL problems across 10 modules**
- **5-page Power BI dashboard**
